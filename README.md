# DEPI Web Projects

Front-end projects I built during the **React Frontend Web Developer** track of the
Digital Egypt Pioneers Initiative (DEPI), Ministry of Communications & IT — 2024.

| Project | What it is | Stack |
|---|---|---|
| [Trafalgar](trafalgar/) | Responsive healthcare landing page | HTML, CSS |
| [Lookscout](lookscout/) | Responsive multi-section marketing site | HTML, CSS |
| [Rayan](rayan-store/) | Multi-section responsive website | HTML, Bootstrap, JS |
| [Connect Four](connect-four/) | Connect Four game in the browser | JavaScript |
| [Team Members](team-members/) | Team page for the Negroo movie site | HTML, Bootstrap |
| [Sign Up](sign-up/) | Sign-up form page | HTML, CSS |
| [To-Do List](todo-list/) | Task list with add / complete / delete | JavaScript |

Open `index.html` to browse all projects. Deployed on Vercel as a static site.
